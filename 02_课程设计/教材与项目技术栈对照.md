# 《语音识别技术及应用》教材与"旅游投诉录音证据智能整理助手"技术栈对照

整理日期：2026-10-07

重叠集中在教材的项目 1、2、4、6、7，即开发环境、特征提取、深度学习编程、端到端原理和普通话识别。项目 3 的 HMM/GMM-HMM 和项目 5 的 N-gram、RNN 歌词生成，在投诉助手里基本用不上，只剩概念价值。投诉助手有一半左右的技术是教材没有的，包括热词、神经网络端点检测、说话人分离、逆文本规范化、时间戳截取、识别后的文本分类、系统级测评和离线部署。

## 一、教材与项目的重叠点

| 教材章节 | 教材讲什么 | 在投诉助手里用在哪 | 重叠程度 |
|---|---|---|---|
| 项目1 开发环境 | 识别框架（前端处理→解码识别）、语料库、Python 库、TensorFlow | 整条流水线就是"前端→识别→后处理"；共享数据池相当于自建语料库；TensorFlow 用在原理实验和第 6、7 组话术分类 | 高 |
| 项目2 特征提取 | 预加重、分帧加窗、STFT、语谱图、Fbank、MFCC | 第 1、2 组用语谱图看噪声；Paraformer、SenseVoice 的输入就是 80 维 Fbank；TensorFlow 小实验提 MFCC | 高，直接用 |
| 项目3 传统声学模型 | HMM、GMM-HMM、孤立词识别 | 不直接用。只有概念相通：HMM 的"对齐"对应时间戳，聚类思想对应说话人分离 | 低 |
| 项目4 DNN 声学模型 | DNN 原理与编程、DNN-HMM、数字命令识别 | TensorFlow 小实验可沿用"MFCC + 小网络识别命令词/数字"，去掉 HMM；第 6、7 组的分类网络也是这套编程方法 | 中 |
| 项目5 语言模型 | N-gram、平滑、评价指标、RNN 语言模型、歌词生成 | 热词的本质是解码时提高专名概率，和语言模型思想相通；第 7 组可用 RNN/LSTM 做分类。困惑度、歌词生成用不上 | 中偏低 |
| 项目6 识别系统 | 传统系统与端到端，CTC、注意力机制 | 识别引擎本身就是端到端模型：SenseVoice-Small 用 CTC 训练；Paraformer 基于注意力，先预测字数再并行解码。学生要懂原理，但不自己训练 | 中高（原理相同，实现换成预训练模型） |
| 项目7 普通话识别 | 中文普通话识别应用 | 第 3 步识别基线，全员跑通并算 CER | 高，但做法升级 |

## 二、教材没有、项目里更新的技术

| 技术 | 用在哪（负责方） | 教材里的情况 | 新在哪里 |
|---|---|---|---|
| 工业级预训练识别模型（Paraformer、SenseVoice），用 sherpa-onnx 离线推理 | 第 3 步（教师基线） | 项目 6、7 自己训练小模型 | 用数万小时数据训练，CPU 上可离线运行，学生不必从零训练 |
| 热词（上下文偏置）：Paraformer 热词，或火山引擎热词、替换词 | 第 3 步（第 5 组） | 只有 N-gram，改词要重训语言模型 | 改一张词表就生效，不用重训模型 |
| 神经网络端点检测（FSMN-VAD、Silero VAD） | 第 2 步（第 1 组） | 只在框架里提到"前端处理"，没有单独实操 | 噪声下更稳，长录音能自动切段 |
| 语音增强（从谱减法、noisereduce 到 RNNoise、DeepFilterNet 等深度降噪） | 第 2 步（第 1、2 组） | 预处理只有预加重、分帧加窗 | 降噪更强；还要用 CER 验证"降噪后识别不一定更好" |
| 说话人分离（CAM++ 等声纹向量 + 聚类，FunASR 和 sherpa-onnx 都提供） | 第 4 步（第 3 组） | 没有 | 自动区分导游和游客 |
| 逆文本规范化（ITN）与标点恢复 | 第 5 步（第 4 组） | 没有 | "两千八百块"变成"2800 元"，证号、电话按格式输出；SenseVoice 自带开关，也可用 WeTextProcessing 等 WFST 规则工具 |
| 字级时间戳 + ffmpeg 截取证据片段 | 第 7 步（第 8 组） | 只有 HMM 对齐的概念 | 模型直接输出每个字的时间，不用单独对齐 |
| 识别结果之上的文本分类（TensorFlow：按字向量化 + 卷积或 LSTM，可选预训练中文 BERT） | 第 6 步（第 6、7 组） | 教材止于"识别出文字" | 属于"识别 + 理解"的级联做法，要测识别错误对分类的影响 |
| 系统级测评：CER 拆成错字/漏字/多字、专名正确率、说话人标错比例、准确率/召回率、误报率 | 全程 | 目录里的"评价指标"在语言模型一章（通常是困惑度） | 每个模块都有前后对比数据，三种录音条件分开测 |
| 数据工程：ffmpeg 统一格式、文件清单、SHA-256 指纹、统一中间格式 | 第 1 步（教师模板） | 用现成语料库 | 自建带标准答案的测评集；各组模块独立开发、最后串联 |
| 离线部署：ONNX、int8 量化、实时率（RTF） | 全程 | 没有 | 不联网、数据不出本地，符合政府场景的隐私要求 |
| 商用云 API 对照（火山引擎录音文件识别） | 第 3 步对照 | 没有 | 用开源与商用的 CER 差距说话 |
| 可信 AI 设计：只标"疑似"、强制人工复核、AI 内容标识、录音同意 | 第 8 步 | 没有 | 政府项目的硬要求，也是现在 AI 工程的通行做法 |

## 三、教材里这个项目用不上的部分

- 项目 3：GMM-HMM 孤立词识别实操（hmmlearn）
- 项目 4：DNN-HMM 混合系统
- 项目 5：N-gram 平滑、困惑度计算、RNN 歌词生成器
- 项目 1：NLTK（面向英文，中文项目用不上）

建议这几部分只讲概念，把课时让给 TensorFlow 小实验和分组专项。

更前沿的方向是大模型语音识别，即把语音编码器接到大语言模型上，例如 Fun-ASR-Nano、Qwen3-ASR，对口音和方言更强。但机房 CPU 跑不动，本项目不用，可以留作教师演示。
