# 选做实验：用 TensorFlow 认中文数字"零到九"

> **这是选做实验**（第 3 周，原理课）。不做不影响后面的正式录音和各组专项任务；想多动手、想弄明白"识别模型到底在学什么"的同学可以做。
> 预计用时：**约 2 节课**（第 1 节录音、切分、看 MFCC；第 2 节汇总全班数据、训练、看结果、改网络）。
> 全程在机房电脑上离线完成，**不需要联网**。

## 一、这个实验做什么

全班每人念 5 遍"零、一、二……九"，自动切成一个字一个文件，然后：

1. 用 numpy 和 TensorFlow 各算一遍 **MFCC**，看看两种写法算出来是不是一样（对应教材**项目 2**"语音特征提取"：预加重、分帧加窗、短时傅里叶变换、语谱图、Fbank、MFCC）；
2. 用全班的录音训练一个**小卷积网络**，让它认出没听过的同学念的数字（对应教材**项目 4**"用深度神经网络构建声学模型"里的"数字命令语音识别"；我们用卷积网络直接分类，不用教材里的 HMM 部分）。

本项目的主流程（识别投诉录音）用的是别人训练好的大模型 SenseVoice。这个小实验让你亲手从头训练一个"迷你识别模型"，体会大模型背后的基本原理：**声音 → 特征（MFCC）→ 神经网络 → 结果**。

## 二、先弄懂 MFCC（大白话版）

一段录音就是一长串数字（每秒 16000 个）。直接看这串数字认不出说的是什么，所以先把它变成"特征"：

| 步骤 | 做什么 | 为什么 |
|---|---|---|
| 1. 预加重 | 每个点减去前一个点的 0.97 倍 | 人说话时高频弱，先把高频提上来一些 |
| 2. 分帧、加窗 | 每 25 毫秒（400 个点）切一帧，每隔 10 毫秒切一次；每帧乘一个两头小、中间大的"汉明窗" | 声音一直在变，但 25 毫秒内可以看成不变；加窗让帧的两头平滑，减少频谱"泄漏" |
| 3. 傅里叶变换 | 算出每帧里各个频率的声音有多强 | 不同的字，各频率的强弱分布不一样（这就是语谱图） |
| 4. 梅尔滤波 | 用 40 个三角形"滤波器"把频率分组加起来，低频分得细、高频分得粗 | 人耳对低频的变化更敏感 |
| 5. 取对数 | 每个数取 log | 人耳对音量的感觉也接近对数 |
| 6. DCT（离散余弦变换） | 把 40 个数再压缩成 13 个 | 去掉相邻滤波器之间的重复信息，留下"音色轮廓" |

结果：每 10 毫秒一行、每行 13 个数。1 秒的录音是 **98 帧 × 13 维**，可以看成一张很小的"图片"，所以能用处理图片的卷积网络来认。

想看自己录音的语谱图和 MFCC：`python tools/show_spectrogram.py 录音文件`（原理课必做部分已经用过）。

## 三、用哪个 Python

| 脚本 | 做什么 | 用哪个 Python |
|---|---|---|
| `split_digits.py` | 把录音切成 50 段 | 便携包的 Python（要用端点检测模型） |
| `mfcc_compare.py` | numpy 和 TensorFlow 各算一遍 MFCC，画图对照 | 都可以；**用机房自带的 Python 运行**才有 TensorFlow 对照（请对照第 2 步切好的 WAV），便携包的 Python 只画 numpy 版 |
| `train_digits.py` | 训练小卷积网络 | **用机房自带的 Python 运行**（装了 TensorFlow；只需要 numpy 和 TensorFlow） |

下面的命令都在项目文件夹里运行。便携包的 Python 写成 `python\python.exe`，机房自带的 Python 写成 `python`（以老师告诉你的为准）。

机房自带的 Python 一般只有 TensorFlow、numpy 和少数常用库，**可能没有 ffmpeg、soundfile、PyYAML**。这两个脚本已经避开了它们：
`mfcc_compare.py` 用 Python 自带的 `wave` 模块直接读切好的 WAV（16000 Hz、单声道、16 位），读不了 `config.yaml` 时图片存到项目的 `outputs\tf_lab\`；`train_digits.py` 只需要 numpy 和 TensorFlow。画图要用 matplotlib，机房的 Python 没有它时 `mfcc_compare.py` 照样打印相关系数，只是不画图。
机房电脑重启会还原、上课不联网，**缺什么库都不要自己装**；需要的话请老师在第 0 周统一准备（例如用 `requirements-tf.txt` 给便携包装上 TensorFlow）。

## 四、实验步骤

### 第 1 步：录音（约 10 分钟）

按 [录音指南第六节](../../docs/guides/recording.md) 录：

- 安静环境，手机离嘴约 30 厘米；
- 按顺序念"零、一、二、三、四、五、六、七、八、九"，**每个字之间停顿约 1 秒**，连念 5 遍，中间不要说别的话；
- 文件名用 `digits-学号后四位.m4a`，例如 `digits-0123.m4a`，**不要用姓名**。

用数据线把录音拷到机房电脑上（不要通过微信、网盘等上传）。

### 第 2 步：自动切成 50 段（约 5 分钟）

```bat
python\python.exe tools\tf_lab\split_digits.py digits-0123.m4a --speaker 0123
```

- `--speaker` 后面写**学号后四位**（只能是数字或英文字母），不要写姓名；
- 程序用端点检测（和流程第 2 步同一个 Silero VAD 模型）找出 50 个字，按顺序存成 `数字/学号后四位_第几遍.wav`，例如 `3/0123_2.wav` 是第 2 遍念的"三"。默认存到数据池的 `digits` 文件夹，加 `--out 文件夹` 可以换位置；
- **段数不是 50** 时，程序会打印每一段的时长，提示"念慢一点、每个字之间停顿约 1 秒，重录"，并且一个文件都不存。看看时长：有一段特别长，多半是两个字连在一起了；段数多了，多半是有杂音、咳嗽或说了别的话；
- 切好后随便点开几段听一听，确认数字和文件夹对得上。

### 第 3 步：MFCC 对照（约 15 分钟）

```bat
python tools\tf_lab\mfcc_compare.py data_pool\digits\3\0123_1.wav
```

- `data_pool\digits\3\0123_1.wav` 换成你自己切好的文件（数据池换过位置的，写实际路径）。机房自带的 Python 请对照切好的 WAV，m4a 等原始录音要用便携包的 Python；
- 图片存到 `outputs\tf_lab\`（文件名如 `3_0123_1_mfcc_compare.png`，前面的 3 是数字），上面一张是 numpy 版（`pipeline/features.py`），下面一张是 TensorFlow 版（`tf.signal`）；
- 程序打印两种算法的**相关系数**（越接近 1 越像，一般在 0.99 以上）。两者不是一模一样：TensorFlow 的梅尔滤波器形状略有不同，第 0 维的"归一化"写法也不同（大 √2 倍），所以按每一维分别算相关系数再取平均；
- 打开 `tools/tf_lab/mfcc_compare.py`，对照上面的表格找到 6 个步骤分别是哪几行；再打开 `pipeline/features.py` 的 `mfcc` 函数对照 numpy 写法；
- 找几个不同数字的录音画一画，比较"一"和"八"、"一"和"七"……的 MFCC 图有什么不同。

### 第 4 步：汇总全班数据

每个人切好的文件夹结构都一样，把大家的 `digits` 文件夹合到一起（同名的数字文件夹合并）即可。一般由老师或组长通过 U 盘、机房共享文件夹汇总到老师电脑的数据池 `data_pool\digits\`，再拷回各自电脑。**至少要有 3 个人的录音才能训练**，人越多结果越可信。

### 第 5 步：训练（约 10 分钟）

```bat
python tools\tf_lab\train_digits.py --data data_pool\digits
```

程序会：

1. 把每段录音补零（或截断）到 1 秒，算 MFCC（98 × 13）；
2. **按人**随机留出约 20% 的同学只做测试（他们的录音训练时一段都不用）。为什么按人分：同一个人念的"三"每次都很像，如果他的录音一半训练、一半测试，网络等于"背过答案"，准确率会虚高；
3. 训练小卷积网络：`Conv2D 16 → MaxPool → Conv2D 32 → GlobalAveragePooling2D → Dense 10`，默认 30 轮（`--epochs 50` 可以改）。每轮打印一行，loss 越来越小、accuracy 越来越大，说明网络在学；
4. 打印**测试集准确率**和**混淆矩阵**（行：实际念的数字；列：网络认成的数字；对角线上是认对的，对角线以外的数字就是认错的）。

### 第 6 步：写小实验报告

报告里写：

- 你的录音切分是否一次成功、重录了几次、原因是什么；
- MFCC 对照图和相关系数，用自己的话解释 6 个步骤；
- 训练用了多少人、多少段，测试是哪几个人，测试集准确率是多少；
- 混淆矩阵里最容易认混的是哪两个数字，猜一猜为什么（提示：比较它们的拼音，比如"一 yī"和"七 qī"）；
- 你改了什么（见下面"可以试试"），准确率有什么变化。

**如实报告**：这只是全班几十个人、安静环境下念的数字，准确率高低都不代表真实场景的效果；人少时结果起伏很大，写清楚用了多少人。

## 五、可以试试

- 网络加一层卷积或 `Dropout`，或者把 `GlobalAveragePooling2D` 换成 `Flatten`（`train_digits.py` 的 `build_model`）；
- 训练轮数多一些、少一些，对比训练集和测试集的准确率（差很多说明"背答案"了，叫过拟合）；
- 数据增强：给训练录音加一点噪声、前后挪一点位置、音量调大调小；
- 把 13 维 MFCC 换成 40 维的梅尔能量（不做最后一步 DCT），哪种更好；
- 用自己在嘈杂教室里念的数字测一测，准确率会掉多少（这就是第 1 组要解决的问题）。

## 六、常见问题

| 问题 | 怎么办 |
|---|---|
| 切分时段数不是 50 | 按提示放慢、每个字之间停顿约 1 秒重录；周围要安静，不要边念边说话 |
| 提示"没装 TensorFlow" | 换成机房自带的 Python 运行（便携包的 Python 没装 TensorFlow）；自己的电脑联网时可以 `pip install -r requirements-tf.txt` |
| `mfcc_compare.py` 提示"不是 16000 Hz、单声道、16 位的 WAV" | 机房自带的 Python 只能直接读第 2 步切好的 WAV；对照原始录音（m4a 等）请用便携包的 Python（只画 numpy 版） |
| `mfcc_compare.py` 提示"没装 matplotlib，没有画图" | 相关系数照样有效；想看图请老师在第 0 周准备好（机房会还原、不联网，不要自己装） |
| 提示"至少需要 3 个人" | 先把更多同学的录音汇总到同一个 `digits` 文件夹 |
| 图上的中文是方框 | 电脑上没有中文字体，不影响结果 |
| 文件夹路径里有中文时出错 | 把项目放到纯英文路径，如 `D:\asr\tiandu` |
| 准确率很低 | 人太少、录音太吵、切分切错了（随机听几段检查），或者训练轮数太少 |
