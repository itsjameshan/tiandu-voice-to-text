# 旅游投诉录音证据智能整理助手 · 项目交接包

这是一门语音识别实训课的全班项目资料。学生分 8 组，做一个原型工具：把游客已经提交的投诉录音或视频，整理成供投诉处理人员核查的“核查初稿”，包括带时间戳、区分说话人的文字稿，标为“疑似、待核查”的片段，以及金额、证号、电话等信息。工具只做提示，不做判定，最后必须由人复核。

**从 [HANDOFF.md](HANDOFF.md) 开始读。** 它是结构化的交接文档，包括课程背景、选题过程、红线、技术栈、分组、数据方案、进度安排和未决事项。

## 说明

- 剧本中的人物、旅行社、店铺、证号和电话全部为虚构，不含任何真实投诉录音或个人信息。
- 项目介绍视频的配音为 AI 合成，所用模型 matcha-icefall-zh-baker 基于标贝（Baker）数据集训练，该数据集**仅限非商业用途**。详见 `04_项目介绍视频/模型说明/` 和 HANDOFF.md 第 14 节。
- 语音模型文件（约 700 MB）没有放进仓库，下载地址见 HANDOFF.md 第 14.4 节。
