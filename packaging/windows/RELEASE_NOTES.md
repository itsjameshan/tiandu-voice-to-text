## 旅游纠纷录音材料整理（教学原型）· Windows 便携包

下载下面的 `tiandu-portable-win64-*.zip`，拷进 U 盘，解压到**纯英文路径**（如 `D:\asr\tiandu`），双击 `selfcheck.bat` 自检，再双击 `start.bat` 启动。不需要联网、不需要安装 Python。

- 包含：Python 3.11 嵌入版、全部依赖、识别和说话人分离模型、ffmpeg、项目代码和文档；不含 TensorFlow。
- 本包在 GitHub 的 Windows 机器上构建并自检通过；机房电脑请老师在开课前实测一次。
- 只能处理按虚构剧本录的录音；识别可能有误，所有标注均为疑似、待核查，必须人工复核。

详细说明见仓库首页 README。
