旅游纠纷录音材料整理（教学原型）· Windows 便携版
==================================================

这是解压即用的版本：不用联网，不用安装 Python，不需要管理员权限。

一、第一次使用
1. 把整个文件夹放到【纯英文路径】下，例如 D:\asr\tiandu 或 U 盘 E:\asr\tiandu。
   路径里不要有中文、空格（例如不要放在“桌面”或“C:\Users\张三\...”下面），否则模型可能加载失败。
2. 双击 selfcheck.bat 做一次自检（约 1 分钟），看到“全部通过”再继续。
3. 双击 start.bat，等黑色窗口出现“Running on local URL”，浏览器会自动打开。
   如果没有自动打开，手动在浏览器地址栏输入 http://127.0.0.1:7860
4. 用完后关闭黑色窗口即可退出。

二、机房电脑会还原怎么办
- 这个文件夹要放在重启后不会还原的盘（问老师），或者直接放在 U 盘里运行。
- 每次下课前，把自己的录音和处理结果（outputs 文件夹里的 zip）拷到 U 盘。

三、同一个机房的其他电脑怎么访问
- 在运行 start.bat 的电脑上查本机 IP（命令行输入 ipconfig），
  其他电脑浏览器打开 http://这台电脑的IP:7860

四、注意（红线）
- 只能处理按虚构剧本录的录音，不要上传真实投诉录音或含个人信息的录音。
- 识别可能有误；所有标注均为“疑似、待核查”，必须人工复核。
- 全部在本机处理，不会上传到任何网站。

五、出问题时
- 先看黑色窗口里的中文提示；再看项目说明 README.md 的“常见问题”一节；
- 还解决不了，把黑色窗口截图发给老师。
