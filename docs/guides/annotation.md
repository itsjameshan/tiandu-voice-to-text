# 标注指南：说话人时间、疑似片段起止

有两种标注，都用免费软件 **Audacity**（老师 U 盘里有安装包）做，导出后用工具转成表格。标的是本组的 AI 测评录音（见 [AI 测评录音说明](recording.md)）。

| 标注 | 给谁用 | 要标多少 | 规范由谁定 |
|---|---|---|---|
| **说话人时间**：谁在什么时间说话 | 第 3 组测"说话人标错的时长比例" | 每组至少 10 分钟（按标出的说话时间算，没标的停顿不算；本组每段 AI 录音约 4—6 分钟，标出的说话时间比这短，一般要标 3 段左右，以 `check_pool.py` 的统计为准） | 第 3 组 |
| **疑似片段起止**：哪一段属于纠纷（购物安排、费用、行程变更、服务态度、威胁消费），从几秒到几秒 | 第 8 组测"片段起止误差" | 每组至少标本组 1 段录音 | 第 8 组 |

> **标哪段录音**：标本组的 AI 录音，哪一段都可以（录音是 AI 合成的，里面没有同学的声音）。
> **先自己标，交了以后再看标准答案**：标准答案包里有现成的说话人和片段标注，放在公开的发布页上，同学也能下载；但考核看的是你们自己标的过程（老师课上抽查），数据池里用的也是你们标的结果。第 6 周交了以后再对照，方法见第四节。

## 一、用 Audacity 标注（两种标注做法一样）

1. 打开 Audacity → 文件 → 打开 → 选数据池里转换好的录音 `data_pool\normalized\G3-S1-Q.wav`（不要标原始录音 `G3-S1-Q-TTS.m4a`，两者时间可能有细微差别）。
2. 菜单 **编辑 → 标签 → 在选区添加标签**（快捷键 Ctrl+B）会新建一个"标签轨"。
3. 在波形上**拖动选中一段**（例如导游说话的那一段），按 **Ctrl+B**，输入标签文字，回车。
   - 说话人标注：标签写角色名，**和剧本角色一致**：`导游`、`游客甲`、`游客乙`、`店员`、`司机`、`经理`……；**录音开头的声明标 `声明`**（它用的是单独的合成声音，算一个说话人）。
   - 片段标注：标签写类别名：`购物安排`、`费用`、`行程变更`、`服务态度`、`威胁消费`。
4. 一段接一段标完。技巧：
   - 按空格键播放/暂停；放大波形（Ctrl+1）能把起止拖得更准；
   - 说话人标注：同一个人连续说的话标成一段；两人同时说话的地方，各标各的（标签可以重叠）；停顿超过 1 秒的空白不用标；
   - 片段标注：从这件事开始说的第一句开头，到说完的最后一句结尾。开头的声明不是疑似片段，不标。
5. 标完：**文件 → 导出 → 导出标签**，保存成 `G3-S1-Q_speakers.txt`（或 `G8-S1-Q_clips.txt`）。
6. 同时**保存 Audacity 工程**（文件 → 保存项目），下次可以接着改。⚠️ 机房会还原，拷到 U 盘。

## 二、转成表格放进数据池

在便携包文件夹打开命令行（或由数据负责人在老师电脑上做）。**直接写进数据池**（`--file` 写录音的文件编号，不带扩展名）：

```bat
:: 说话人标注 → data_pool\annotations\speakers\G3-S1-Q.csv
python\python.exe tools\labels_to_csv.py G3-S1-Q_speakers.txt --pool D:\data_pool --file G3-S1-Q --kind speakers

:: 疑似片段标注 → data_pool\annotations\clips\G8-S1-Q.csv
python\python.exe tools\labels_to_csv.py G8-S1-Q_clips.txt --pool D:\data_pool --file G8-S1-Q --kind clips
```

也可以先转成一个单独的表格（不放进数据池），自己检查后再交给数据负责人（不写 `--kind` 时按说话人标注转换）：

```bat
python\python.exe tools\labels_to_csv.py G3-S1-Q_speakers.txt G3-S1-Q.csv
python\python.exe tools\labels_to_csv.py G8-S1-Q_clips.txt G8-S1-Q.csv --kind clips
```

转换后的表格都是三列，第一行是列名（UTF-8 带 BOM，Excel 能直接打开）：

| 标注 | 列名 | 每列写什么 |
|---|---|---|
| 说话人时间 | `start,end,speaker` | 开始时间（秒）、结束时间（秒）、角色名（如 `导游`） |
| 疑似片段 | `start,end,label` | 开始时间（秒）、结束时间（秒）、类别名 |

- 时间以秒为单位，保留 3 位小数，表格按开始时间排好。
- 片段标注的类别名只能是 `购物安排`、`费用`、`行程变更`、`服务态度`、`威胁消费` 这 5 个之一。写界面上的显示名 `消费施压` 也可以，表格里会存成 `威胁消费`。写别的（如 `正常讲解`、`其他`、`投诉`、`疑似·费用`、角色名）会报错、不转换——正常讲解和其他不用标。

转换时会检查，有错就**一条也不写**，并说明是第几个标签、什么问题：

- 每个标签都要拖选一段：起止时间相同的"点"标签（没拖选就按了 Ctrl+B）会报错；
- 说话人标注每个标签都要写角色名（开头的声明写 `声明`）；
- 用 `--pool --file` 时还会提醒（仍然转换）：角色名不在这个剧本的角色表里（如"导游"写成"导"；`声明` 不算写错）、标签超出了录音时长（可能标错了录音）。

其他说明：

- 同一段录音再转换一次会**覆盖**原来的表格：在 Audacity 里改好标签、再导出、再转换即可。
- Audacity 导出的标签文件是 UTF-8 还是 GBK（中文 Windows 的 ANSI）编码都能读；在语谱图上框选过的标签会多一行以 `\` 开头的频率信息，转换时自动跳过。

## 三、怎么检查标得好不好

- 第 3 组、第 8 组各抽查几段别组的标注：在 Audacity 里同时打开录音和标签文件（文件 → 导入 → 标签），边听边看。
- 常见问题：起止拖得太宽（包进了别人的话）、角色名写错（"导游"写成"导"）、漏标了短句（"嗯""好"也是一句话）、开头的声明没标或没写成 `声明`。
- `python\python.exe tools\check_pool.py --pool D:\data_pool` 会统计每组已经标了多少分钟：按标签覆盖的时长算，两人同时说话（标签重叠）的部分只算一次，没标的停顿不算。

## 四、用标准答案对照（第 6 周，交了以后再做）

标准答案是合成录音时同时得到的（见 [AI 测评录音说明](recording.md)第九节）。**一定要等本组的标注交了以后再对照。**

1. 老师发标准答案包 `tiandu-ai-answer-key-v1.zip`，解压到纯英文路径，如 `D:\asr`。如果弹出"替换或跳过文件"（录音包里也有一个 `README.txt`），选"替换"就行，两个 `README.txt` 内容一样。Audacity 标签在 `D:\asr\ai_recordings\answer_key\audacity_labels\`：`G3-S1-Q.speakers.txt` 是说话人，`G3-S1-Q.clips.txt` 是疑似片段。
2. 在 Audacity 里打开同一段录音 `data_pool\normalized\G3-S1-Q.wav`（或者打开自己保存的工程），用 **文件 → 导入 → 标签** 导入自己的标签文件（如 `G3-S1-Q_speakers.txt`，工程里已经有就不用），再导入标准答案的 `G3-S1-Q.speakers.txt`（片段标注导入同一段录音的 `G3-S1-Q.clips.txt`）。两条标签轨上下排着，边听边对照。
3. 先看懂标准答案的标签：
   - 说话人标签是**一句台词一个标签**，同一个人连着说的几句没有合并；时间是每句合成语音的起止（去掉了首尾静音），重叠的台词时间会交叠。你们按规范把同一个人连续说的话标成一段，所以标签个数对不上是正常的；
   - 片段标签是把连续几句同一个疑似类别的台词连成一个片段，类别来自剧本台词的类别；
   - 起止差一点点是正常的，每个人拖选的位置不会完全一样。
4. 记下差别，填**对照记录**：

   | 录音编号 | 标注 | 时间（分:秒） | 自己标的 | 标准答案 | 差别类型 | 说明 |
   |---|---|---|---|---|---|---|
   | （例）G3-S1-Q | 说话人 | 2:10 | 游客甲 | 游客乙 | 角色标错 | 两人声线相近，没听出来 |
   | | | | | | | |

   差别类型：角色标错、漏标（短句"嗯""好"、重叠的地方）、多标、起止拖得太宽或太窄、类别不同（片段）、片段漏标或多标、其他。
5. **数据池里的标注不换成标准答案**：不要把标准答案的表格拷进数据池代替自己的标注。对照后发现自己标错了的，可以**重新听录音**，按规范改正：先把导入的标准答案标签轨删掉（点那条轨道左上角的"×"；Audacity 导出标签时会把所有标签轨一起导出），再在 Audacity 里改自己的标签、重新导出、再转换（第二节，会覆盖原来的表格），冻结第 1 版之前改完。**不能照抄标准答案的起止时间**；改了什么写进对照记录。
6. 第 3 组汇总全班说话人标注和标准答案的偏差，第 8 组汇总全班片段标注的偏差（常见的差别是什么、哪些剧本最容易标错）。
