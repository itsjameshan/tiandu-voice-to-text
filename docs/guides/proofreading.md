# 参考文本校对指南

## 为什么要校对

字错率 = 识别结果和**参考文本**相比的错字、漏字、多字之和 ÷ 参考文本总字数。

参考文本必须是录音里**实际说了什么**。大家录音时会即兴、改口、打断、漏说，和剧本不完全一样。如果直接拿剧本当参考文本，人说错的地方会被算成"识别错"，测出来的字错率就不可信，后面各组的"改进"也说不清。

所以：**72 段录音，每段都有一份自己的参考文本**（`data_pool/references/G1-S1-Q.txt` 这样的文件），开始时内容照抄剧本台词，由同学对照录音改成实际说的话。**每段由两个人各校对一遍。**

## 怎么校对（用网页"数据校对"页）

1. 启动网页工具，打开"**数据校对**"页。
2. "数据池路径"填老师告诉你的路径（如 `D:\data_pool`）；"校对人"填你的学号后四位。
3. "录音"下拉框里选要校对的录音（如 `G1-S1-Q`），点"**生成对照**"。工具会先把录音识别一遍（第一次要等一会儿，之后会记住结果）。
4. 看对照表，每一行是一小段话：开始时间、结束时间、**识别结果**、**参考文本**（剧本里对应的那部分）、**是否不同**。
5. **只重点听"不同"的那些行**：点这一行就会播放这一段原声。听完判断：
   - 人确实是照剧本说的，是**识别错了** → 参考文本**不改**；
   - 人说的和剧本不一样（改口、多说、漏说、说错名字）→ 按**实际说的**改参考文本；
   - 听不清 → 多听几遍；实在听不清就保留剧本原文，在"备注"里记一笔。
6. 页面下方的文本框就是参考文本，直接修改，改完点"**保存参考文本**"。工具会记下你的校对人编号和时间。
7. 保存后点"生成对照"再看一遍，"不同"的行应该只剩识别错的。

## 写法规则（和剧本一致）

- **数字写汉字读法**，按实际读法写："两千八百块""零八七一 零零零零 六六八八""下午三点四十"。不要写阿拉伯数字。
- 证号里的字母用大写拉丁字母："YN 零零零零 三七二一"。
- 语气词照实写："嗯""啊""那个""就是说"——说了就写，没说就删。
- **动作、停顿、笑声不写**（剧本 `direction` 里的内容本来就不在参考文本里）。
- 一句话说到一半被打断，就写到被打断的地方。
- 两个人同时说话：都能听清就按先后都写上；听不清的那个人的话可以删掉，在备注里写"重叠"。
- 标点不重要（计算时会去掉），但可以保留，方便阅读。
- 虚构名称说错了（比如把"雾隐行舟"说成"雾影行舟"），**按说错的写**——第 5 组正需要这样的例子。

## 两人交叉校对

- 第一个人校对完保存；第二个人打开同一段，再对照一遍，有不同意见时两人一起听、商量着改。
- 验收时，每段录音要有**两个不同的校对人**记录才算通过（`tools/check_pool.py` 会统计）。
- 第 4 组额外抽查所有参考文本里的数字读法，第 5 组额外抽查专名写法。

## 不能做的

- 不要为了让字错率好看，把参考文本改成识别结果。参考文本只跟着**录音里人说的话**走。
- 不要在参考文本里写任何真实姓名。
