## 一、你们组负责什么

**一句话**：流水线第 6 步要给每段话分一个类别（7 选 1）。你们把模板的卷积网络改成 **LSTM（模型 B）**——一种按顺序、一个字一个字读句子的神经网络——在同样的条件下和"关键词规则"基线、和第 6 组的卷积网络（模型 A）比较，重点看两件事：**"服务态度"认不认得出来**、**正常讲解会不会被误报**——用数字说明有没有变好（没变好也如实写）。

- **对应步骤**：⑥ 话术分类，基线代码在 `pipeline/step6_classify.py`（关键词规则）。
- **槽位**：`classify`（话术分类）。输入是一串文字，输出是同样多的类别，每个都是下面 7 个之一：

  | 类别 | 标签（显示在核查初稿上） | 意思（摘自 `data/labels.json`） |
  |---|---|---|
  | 购物安排 | 疑似·购物安排 | 推荐、安排、推销购物或进店，商品介绍，游客对购物的回应 |
  | 费用 | 疑似·费用 | 价格、自费项目、团费、退款、小费等金额相关 |
  | 行程变更 | 疑似·行程变更 | 取消、压缩、调换行程或时间安排变动 |
  | 服务态度 | 疑似·服务态度 | 催促、敷衍、不耐烦，以及对态度的抱怨和道歉 |
  | 威胁消费 | **疑似·消费施压** | 以行程、住宿、服务等为条件，含蓄地施压要求消费（措辞温和，无辱骂、无人身威胁） |
  | 正常讲解 | （不标） | 景点介绍、安全提醒、集合通知等正常导游工作 |
  | 其他 | （不标） | 寒暄、问路、附和、与上面无关的话 |

- **为什么重要**：核查初稿里的"疑似片段"就是按这一步的标签截出来的。漏标了，工作人员可能错过关键的话；**误报**（把正常讲解标成疑似）会冤枉导游。所以不管模型多好，标签都只是"疑似、待核查"，**必须人工对照原声复核**。
- **你们组特别要盯的一对类别：服务态度 和 正常讲解**。导游催老人"快点快点"是服务态度，导游提醒"跟紧我，别走散了"是正常讲解；导游敷衍孩子"有什么好问的"是服务态度，导游认真讲石林怎么形成是正常讲解。两类用的字很像，意思差得远。你们的三个剧本就是专门为这个写的（第三节）。
- **你们的产出**：在 `pipeline/groups/g7_classifier_b.py` 的 `build_model` 里写出模型 B（LSTM），测出"**基础结果 + 改进后结果 + 对比数据**"，写成报告并答辩。
- **主要指标**：各类**准确率（精确率）**和**召回率**、**混淆矩阵**、**误报率**（全部剧本一个、只看第 8 组剧本一个）。主结果用"**按组留一**"，"随机划分"只作对照。另外要和第 6 组的模型 A 在**同样的条件**下比较（第七节 7.5）。
- **数据阶段（第 1—6 周）另外分管两件事**：
  1. 第 5—6 周审核 AI 生成的补充句子的**后一半**（X0483—X0964，共 482 句；前一半 X0001—X0482 由第 6 组审核）；
  2. 第 6 周抽查剧本台词（`data/lines.csv`）的类别标注，把有问题的地方报给老师。

## 五、基线做法是怎么工作的

### 5.1 第 6 步在流水线里的位置

```
第 3 步识别出的文字 ─▶ 第 4 步分出说话人 ─▶ 第 5 步数字规范化
        ─▶ 第 6 步 话术分类（classify）   ← 第 6、7 组的槽位
              │  每段文字 → 7 个类别之一 → 标签（前 5 类写成"疑似·……"，后 2 类留空）
              ▼
        第 7 步疑似片段（按标签截音频，第 8 组）─▶ 第 8 步核查初稿 ─▶ 人工复核
```

几点要记住：

- **标签不是你们拼的**：`classify_segments` 拿到你们给的类别，再用 `label_output(类别)` 写成标签。你们的函数只要返回 7 个类别名之一（数据里写"威胁消费"，不写"消费施压"）。
- **先归一，再分类**：关键词规则和 TensorFlow 模型都先用 `normalize_for_classification` 把文字整理一遍：连续的阿拉伯数字、两个以上连续的汉字数字都换成一个 `#`，去掉标点和空格。所以"二十分钟"和"20分钟"都变成"#分钟"，识别结果是汉字读法还是阿拉伯数字都一样。
- **第 4、5 步和你们的关系**：训练和 `evaluate.py classify` 直接用台词原文，第 4、5 步不参与；网页"剧本文本演示"里第 5 步会先把汉字数字改成阿拉伯数字，归一后都变成 #，大多数句子没有影响，但"块"改成"元"这类改写会传到第 6 步。

### 5.2 关键词规则基线（`classify_baseline`，按顺序做五件事）

1. 关键词表在 `pipeline/rules_keywords.json`：每个类别一组短词。和你们最有关的两类：
   - "服务态度"有"态度""道歉""对不起""抱歉""是我不对""催""赶紧""快点""耐心""脸色""迟到""再说吧"等；

   - "其他"没有关键词。
2. 句子和关键词都先归一（见 5.1）。
3. 数一数每个类别的关键词在句子里一共出现了几次（`count_hits`）。
4. 次数最多的类别胜出；一样多时按 `priority` 的先后选：威胁消费 → 服务态度 → 行程变更 → 费用 → 购物安排 → 正常讲解 → 其他（`pick_category`）。

- G7-S2 第 14 句"您跟紧一点，别老停下来"：是在催老人（服务态度），可"跟紧"是"正常讲解"的关键词；
- G7-S3 第 4 句"有什么好问的，石头就是石头嘛，拍拍照就行了"：是敷衍（服务态度），可句子里有"拍照"。

### 5.3 模板的卷积模型（`build_baseline_model`，第 7 周训练一次）

TensorFlow 模型是"字级"的：把一句话看成一串字。模板的卷积模型从文字到类别经过这几步：

```
"您跟紧一点，别老停下来"
   │ ① 归一：数字串换成 #，去掉标点
   │ ② 查字表：每个字换成一个编号（字表里没有的字是 1），不够 64 个字后面补 0，超过就截断
   ▼
 一句话 = 64 个编号
   │ ③ Embedding：每个编号变成 64 个数（"字向量"），意思相近的字，训练后向量也会接近
   ▼
 64 个字 × 每字 64 个数
   │ ④ Conv1D：128 个"小窗口"（卷积核），每个一次看相邻 3 个字，看到自己在意的字组合就给出一个大的数
   │ ⑤ GlobalMaxPooling1D：每个小窗口只留它在整句里最强的那一下反应 → 128 个数
   │ ⑥ Dense + softmax：128 个数 → 7 个类别各自的概率，加起来等于 1
   ▼
 取概率最大的那个类别
```

- **字表**（`build_vocab`）只用训练句子建：出现多的字编号小，编号 0 留给补位，1 留给不认识的字。
- **训练**（`tools/train_classifier.py` 的 `train_model`）：让模型看很多"句子 + 正确类别"，每看一批（32 句）就按"猜错了多少"（损失）微调里面的数；全部句子看一遍叫"一轮"，模板训练 15 轮；**不加类别权重**；随机种子固定，同一台电脑上重复运行结果基本一样。
- **每句最多取 64 个字**（训练脚本里的 `MAX_LEN`）。
- 训练好的模型是一个文件夹 `models/classifier_g7/`，里面三个文件：`model.h5`（模型）、`vocab.json`（字表）、`meta.json`（类别顺序、每句取几个字、训练日期、用没用补充句子、最终模型训练用了几秒 `train_seconds` 等）。

第 6 组的模型 A 就是在这个卷积模型上改的；你们要把中间的"卷积"换成 LSTM。

### 5.4 LSTM 是怎么读句子的（你们要写的模型 B）

LSTM（长短期记忆网络）是一种"循环神经网络"：**按顺序一个字一个字地读，手里一直带着一份"记忆"**，每读一个字就更新一次记忆，读完最后一个字，记忆就是它对整句话的"印象"。

```
"您跟紧一点，别老停下来"
   │ ① 归一、查字表、补 0（和卷积模型完全一样）
   ▼
 您 跟 紧 一 点 别 老 停 下 来 0 0 0 …… 0        （一共 64 个编号）
   │ ② Embedding：每个字变成 64 个数；mask_zero=True 给补位的 0 做上记号，后面的层会跳过它们
   ▼
   │ ③ LSTM：从"您"开始往后读，记忆（比如 64 个数）一路带着走：
   │      读到"您跟紧一点"……
   │      读到"别老停下来"……
   │    读到最后一个真正的字（"来"）就停下（补位的 0 被跳过），交出最后的记忆
   ▼
 64 个数（整句话的"印象"）
   │ ④ Dense + softmax：→ 7 个类别的概率
   ▼
 取概率最大的那个类别
```

- **记忆是怎么更新的**：LSTM 里有三个"门"，都是训练出来的：**遗忘门**决定旧记忆留多少，**输入门**决定新读到的字记多少，**输出门**决定交出多少。打个比方：读到"别老停下来"时，模型可能学会"前面的'跟紧'不是普通提醒"。这只是打比方，**模型实际学到了什么，要靠测出来**。
- **为什么一定要 `mask_zero=True`**：句子不够 64 个字时，后面补的都是 0。单向 LSTM 从左往右读，如果不跳过这些 0，读完真正的字以后还要再"读"几十个 0，最后交出的记忆里全是补位的影响。设了 `mask_zero=True`，编号 0 就被当成"不是字"，LSTM 读到真正的最后一个字就停。（字表里编号 0 本来就是留给补位的，所以这样设不会丢字。）
- **双向 LSTM**（`Bidirectional`）：一个 LSTM 从左往右读、另一个从右往左读，两份记忆拼在一起。读到句子开头时也"知道"后面说了什么。
- **和卷积比**（这是两种结构**设计上**的不同，哪种更适合这批短句，要靠你们测出来）：

  | | 卷积（模型 A，第 6 组） | LSTM（模型 B，你们） |
  |---|---|---|
  | 怎么看句子 | 很多"小窗口"，每个一次看相邻几个字，在句子哪里出现都行 | 按顺序一个字一个字读，带着记忆往后走 |
  | 设计上擅长 | 抓住关键的几个字组合（"多少钱""心里有数"） | 把前后连起来看（"跟紧一点"后面还有"别老停下来"） |
  | 训练速度 | 较快（各个窗口可以同时算） | 较慢（要一个字接一个字算） |
  | 要注意 | 窗口宽度 | 补位的 0（`mask_zero`）；句子很长时前面的内容可能被"忘掉" |

### 5.5 怎么测：按组留一、随机划分、补充句子

- **按组留一**（主结果）：用 7 个组的台词训练、测剩下 1 个组，轮 8 次，每句台词正好被测一次，汇总成一个混淆矩阵。相当于"用别的同学写的句子来测"。
- **随机划分**（对照）：每个类别随机取 20% 的台词做测试。同一个剧本的相似句子会同时出现在训练和测试里，**结果会虚高**，只作对照。

### 6.0 必做：把卷积换成 LSTM（模型 B 的起点）

把 `g7_classifier_b.py` 改成下面这样（整份文件，函数名、参数都没变）：

```python
from pipeline.methods import register
from pipeline.step6_classify import classifier_dir, classify_with_model

MODEL_DIR_NAME = "classifier_g7"

# ---- 第 7 组：模型 B 的参数（每次只改一个，改完重新训练、记进试验记录表）----
EMBED_DIM = 64        # 每个字变成几个数（和模板的卷积模型一样）
LSTM_UNITS = 64       # LSTM 的隐藏单元数：一边读一边"记在心里"的数有几个


def build_model(vocab_size: int, num_classes: int, max_len: int):
    """第 7 组的模型 B（LSTM）。TensorFlow 只能在函数里面导入（网页工具在没有 TensorFlow 的电脑上也要能启动）。"""
    import tensorflow as tf

    model = tf.keras.Sequential([
        tf.keras.Input(shape=(max_len,), dtype="int32"),                      # 输入：每句 max_len 个字编号
        tf.keras.layers.Embedding(vocab_size, EMBED_DIM, mask_zero=True),      # 每个字变成 EMBED_DIM 个数；补位的 0 做上记号
        tf.keras.layers.LSTM(LSTM_UNITS),                                      # 从左往右一个字一个字地读，读完给出整句的"印象"
        tf.keras.layers.Dense(num_classes, activation="softmax"),              # 7 个类别的概率
    ])
    model.compile(optimizer="adam", loss="sparse_categorical_crossentropy", metrics=["accuracy"])
    return model


@register("classify", "g7")
def classify_g7(texts: list[str], cfg: dict) -> list[str]:
    """用 models/classifier_g7/ 里训练好的模型分类；用不了时退回关键词规则。"""
    return classify_with_model(texts, cfg, classifier_dir(cfg, MODEL_DIR_NAME))
```

逐行说明（答辩时每个人都要能讲）：

- `tf.keras.Sequential([...])`：一层接一层的模型，数据从上往下流。
- `tf.keras.Input(shape=(max_len,), dtype="int32")`：每句话是 `max_len` 个整数编号。
- `Embedding(vocab_size, EMBED_DIM, mask_zero=True)`：每个编号变成 `EMBED_DIM` 个数；`mask_zero=True` 让后面的 LSTM 跳过补位的 0（见 5.4）。
- `LSTM(LSTM_UNITS)`：按顺序读，只交出读完最后一个字时的记忆（`LSTM_UNITS` 个数）。
- `Dense(num_classes, activation="softmax")`：变成 7 个类别的概率。
- `compile(...)`：和模板一样的优化方法（adam）和损失函数，这样和卷积模型比时只差"卷积 + 最大池化 换成 LSTM"这一处（LSTM 必须配的 `mask_zero=True` 一起算在这一处里）。

注意：

- 原来文件开头的 `from pipeline.tf_classifier import build_baseline_model` 现在用不到了，**要删掉**（自动测试的代码检查会查没用到的 `import`）。
- **一直用 `tf.keras.Sequential` 这种一层接一层的写法**。我们在较新的 TensorFlow（2.21）上试过：用"函数式写法"（`tf.keras.Model(输入, 输出)`）再加上 `mask_zero=True` 的模型，存成 `model.h5` 以后再加载会报 `Unknown layer: 'NotEqual'`，网页工具和测评工具就用不了它（会退回关键词规则）。用 `Sequential` 写的在 2.15 和 2.21 上都能正常保存、加载。
- 改完先检查文件、再用随机划分快速跑一次，确认能训练、能保存（这一次的分数不算数），然后再按组留一正式训练（命令见第七节 7.2）。

### 方向 2（中等）：补充句子、类别权重

**问题**：按组留一测第 7 组时，训练集里的剧本台词只剩 57 句"服务态度"（5.5）；而"其他"有 212 句、"费用"有 208 句。

**第一步：用 / 不用补充句子对比**（这一步必须做，报告里两种结果都要有）。训练脚本默认用补充句子；不用补充句子的命令见报告模板 `reports\g7\README.md` 第 5 节的第二条（按组留一、不用补充句子），照着写。两次只差这一处，其他都一样。看"服务态度"的召回率和第 7 组那一折的正确率有什么变化。

**第二步：类别权重**。思路是训练时**分错某一类扣分更多**，模型就会更在意这一类。训练脚本不是本组文件，所以把权重写进你们自己的损失函数里，在 `build_model` 的 `compile` 里用它（这几行放在 `build_model` 前面）：

```python
from pipeline.data import LABEL_NAMES   # 7 个类别名，顺序和模型输出的 7 个概率一致（这一行放在文件开头的 import 里）

# 第 7 组：各类别的权重（举例，不代表会更好）。没写的类别权重是 1.0
CLASS_WEIGHTS = {"服务态度": 2.0}


def make_weighted_loss():
    """带类别权重的损失函数：分错权重大的类别，"扣分"更多。"""
    import tensorflow as tf

    # 按 LABEL_NAMES 的顺序排好每个类别的权重
    weights = tf.constant([CLASS_WEIGHTS.get(name, 1.0) for name in LABEL_NAMES], dtype="float32")

    def weighted_loss(y_true, y_pred):
        y_true = tf.cast(tf.reshape(y_true, [-1]), "int32")                    # 每句的正确类别编号
        loss = tf.keras.losses.sparse_categorical_crossentropy(y_true, y_pred)  # 每句原来的扣分
        return loss * tf.gather(weights, y_true)                                # 乘上这一类的权重

    return weighted_loss
```

然后把 `build_model` 里的 `loss="sparse_categorical_crossentropy"` 改成 `loss=make_weighted_loss()`。（保存时不用管这个函数：网页和测评工具加载模型只用来预测，不需要损失函数。）

**要想清楚的地方**：

- "服务态度"的权重调大以后，它的召回率可能上去，但模型也可能把更多"正常讲解"（比如"跟紧""注意脚下"这类提醒）猜成"服务态度"——**误报率**要一起看，两个都写进报告。
- 权重写多少，要说得出理由（比如参考各类句数的比例），不要只是"试了一堆挑最好的"。
- 第 6 组也可能做类别权重（他们关心"威胁消费"）。和他们比的时候，写清楚两边各自加没加权重。

### 方向 3（难一点）：LSTM 后面接池化，和卷积比"哪种更适合短句分类"

**思路**：6.0 的 LSTM 只交出"读完最后一个字时的记忆"。可以让它**每读一个字都留下一份记忆**（`return_sequences=True`），再把这些记忆取平均（`GlobalAveragePooling1D`，它认得补位的记号，只对真正的字取平均），句子开头的信息就不容易被"忘掉"。还可以在后面加一层 Dropout（训练时每次随机"关掉"一部分数），防止模型死记训练句子。仍然用 `Sequential` 写：

```python
DROPOUT = 0.5              # 第 7 组：训练时每次随机关掉一半（举例）


def build_model(vocab_size: int, num_classes: int, max_len: int):
    """第 7 组的模型 B：双向 LSTM 每个字都留下记忆，取平均后再分类。"""
    import tensorflow as tf

    model = tf.keras.Sequential([
        tf.keras.Input(shape=(max_len,), dtype="int32"),
        tf.keras.layers.Embedding(vocab_size, EMBED_DIM, mask_zero=True),
        tf.keras.layers.Bidirectional(
            tf.keras.layers.LSTM(LSTM_UNITS, return_sequences=True)),          # 每读一个字都留下一份记忆
        tf.keras.layers.GlobalAveragePooling1D(),                               # 把每个字的记忆取平均（补位的 0 不算）
        tf.keras.layers.Dropout(DROPOUT),                                       # 只在训练时起作用
        tf.keras.layers.Dense(num_classes, activation="softmax"),
    ])
    model.compile(optimizer="adam", loss="sparse_categorical_crossentropy", metrics=["accuracy"])
    return model
```

**要想清楚的地方**：

- 这一步同时改了三处（双向、池化、Dropout）。想知道是哪一处起作用，就一处一处加，各测一次。
- 本组文件说明里还提到"注意力"。注意力层要用函数式写法（`tf.keras.Model(输入, 输出)`），在较新的 TensorFlow 上会碰到 6.0 说的"存成 model.h5 再加载报错"的问题。想试先问老师，并且一定先用第七节 7.7 的命令确认模型能被 `classify_g7` 加载、没有"改用关键词规则"的提示，再写进报告。
- 三个方向都单独测过以后，可以把效果好的组合起来再测一次；报告里写清楚每一步的对比，最后和第 6 组的模型 A 比（第七节 7.5）。

### 7.4 怎么看结果

训练报告（如 `train_g7_logo_extra.md`）里有这几块：

1. **基本信息**：模型、测评方式、用没用补充句子（用了多少句）、训练轮数、每句取几个字、TensorFlow 版本、生成时间——这些都要抄进你们的报告，别人才能重做。
2. **总体结果**：7 类正确率、误报率（全部剧本）、误报率（只看第 8 组剧本），都写成"比例（句数/总句数）"的样子。
3. **各类准确率与召回率**：表头是"类别 | 标准答案句数 | 预测成该类的句数 | 预测对的句数 | 准确率 | 召回率"。
   - **准确率（精确率）**：被分到这一类的句子里，真属于这一类的比例；
   - **召回率**：真属于这一类的句子里，被分对的比例。两个都要看。
4. **混淆矩阵**：行是标准答案，列是模型预测，对角线上是分对的句数。先看"服务态度"那一行：分错的都跑到哪一列去了？是"其他"，还是"正常讲解""行程变更"？再看"正常讲解"那一行：被分进前 5 类的那些格子，就是误报；其中有多少跑进了"服务态度"那一列？
5. **各组结果**：按组留一时每一折测一个组。第 7 组那一折的正确率，和别的组比怎么样？想想为什么（5.5）。

**每句的预测**：用 Excel 打开 `train_g7_logo_extra_predictions.csv`，在 `correct` 一列筛选"错"，再按 `label` 筛选"服务态度"或"正常讲解"，看看分错的是哪些句子、有没有共同点（太短？像"好了好了"这样没有实际内容？催促和提醒说得很像？复述别人的话？）。报告里挑几句当例子。

**看数字时要小心**：

- 第 7 组那一折只有 124 句，第 8 组剧本的"正常讲解"只有 49 句，多分对一两句，比例就会变一截。差值只有一两句时，不要急着说"变好了"。
- 换一台电脑或换 TensorFlow 版本，结果会有小幅差别（训练报告的"局限"里也写了）。基线和改进要**在同一台电脑、同一个 TensorFlow 版本**上跑。
- 剧本台词是照着类别写的，说法比真实录音规整；剧本数据上的测评结果不代表真实场景的效果。

**训练用时**（报告模板第 6 节有这一行）：对比表和试验记录表里的"训练用时"统一用按组留一时 8 折"用时"之和（模板第 6 节的口径；也可以看 `models\classifier_g7\meta.json` 里 `evaluation` 的 `seconds`，用记事本打开就能看）。跑完马上记下，因为下次训练会覆盖 `meta.json`。`train_seconds`（最终模型的训练用时）只作参考。比用时一定要**同一台电脑**，不然没有意义。

## 十、常见坑

1. **用便携包的 `python\python.exe` 跑训练**：会提示"没有安装 TensorFlow，不能训练"。训练要用机房自带的 `python`。
2. **机房 Python 提示缺某个库**：本组训练只需要 TensorFlow 和 numpy（numpy 随 TensorFlow 一起装）；如果报 `No module named …`，把提示拍照找老师（装库要联网）。训练脚本提示"导入 g7 的模型文件失败"时，后半句叫你装 cn2an、pypinyin，可以不管：多半是 `g7_classifier_b.py` 写错了，或者在文件开头导入了机房 Python 没有的库，先用 7.1 第 3 步的命令检查本组文件。
3. **"python 不是内部或外部命令"，或者一运行就报 `TypeError`、`SyntaxError`**：机房 Python 不在系统路径里，或者版本太旧（本项目的代码需要 Python 3.10 及以上）。把完整报错拍照给老师。
4. **对比表差值全是 0**：多半是模型根本没被用上——便携包没有 TensorFlow，或者 `models\classifier_g7\` 里没有模型，`g7` 悄悄退回了关键词规则（5.7）。看命令行或网页摘要里有没有"改用关键词规则"的提示。
5. **忘了 `mask_zero=True`**：模型照样能训练，不会报错，但 LSTM 会把补位的 0 也"读"进去，结果可能很怪。每次改 `build_model` 都看一眼 `Embedding` 那一行。
6. **用了函数式写法，模型加载不了**：在较新的 TensorFlow 上，`tf.keras.Model(输入, 输出)` 写法加上 `mask_zero=True`，存成 `model.h5` 后再加载会报 `Unknown layer: 'NotEqual'`，`g7` 就退回了关键词规则。一直用 `tf.keras.Sequential` 写（6.0）。
7. **池化前忘了 `return_sequences=True`**（方向 3）：LSTM 只交出最后一份记忆，后面的 `GlobalAveragePooling1D` 会报维度不对的错。
8. **以为训练卡住了，把黑色窗口关了**：LSTM 训练比卷积慢，按组留一要训练 9 次模型。看黑色窗口里"第几折"有没有往下走，耐心等；想快点确认能跑，先用随机划分。
9. **报告被覆盖**：`train_g7_logo_extra.md` 这些文件名是固定的，再跑一次就把上一次盖了。每组试验跑完马上挪进子文件夹。
10. **`models\classifier_g7\` 不是你以为的那个模型**：每次训练都会覆盖它，最后一次训练是什么设置，网页和测评用的就是什么。交模型、做第 9 周验证前，确认最后一次跑的是定下来的最终设置。
11. **只看 7 类正确率**："其他"最多，多猜"其他"正确率也不低。一定要看各类召回率（尤其"服务态度"）和误报率。
12. **拿随机划分当主结果**：同一个剧本的相似句子同时在训练和测试里，结果会虚高。主结果只用按组留一。
13. **拿最终模型在台词上测**：最终模型是用全部台词训练的，再拿这些台词测，等于考过的题再考一遍（7.3）。
14. **和第 6 组比的时候条件不一样**：补充句子版本、训练轮数、测法、电脑、TensorFlow 版本都要一样才能直接比（7.5）。训练用时尤其要同一台电脑。
15. **在文件开头写 `import tensorflow`**：网页工具在没有 TensorFlow 的电脑上会启动不了，自动测试也会失败。TensorFlow 只能在函数里面导入。
16. **没用到的 `import` 没删**：按 6.0 改写后，`build_baseline_model` 就用不到了，要删掉那一行导入，不然自动测试的代码检查会报错。
17. **改了函数名或参数**：训练脚本找的是 `build_model(vocab_size, num_classes, max_len)`，网页找的是 `classify_g7(texts, cfg)`，改了就找不到。
18. **在本组文件里改 `max_len`**：句子长度由训练脚本统一定，网页和测评工具按 `meta.json` 里的 `max_len` 补位；在 `build_model` 里自己改，两边就对不上了。
19. **提交了 `models\classifier_g7\`**：模型文件大，不进仓库，用 U 盘交给老师。
20. **差一两句就说"变好了"**：第 7 组那一折只有 124 句，一两句就是一截；换电脑、换 TensorFlow 版本结果也会有小幅差别。差值很小时如实写"差别不大"。
21. **把剧本台词抄进补充句子，或改补充句子时照着台词改**：测试集就是剧本台词，等于"把考题放进了练习册"。检查脚本能查出一字不差的，只差一两个字的要靠人看。
22. **为了分数改标准答案**：`data/lines.csv` 的类别不能为了让结果好看而改；觉得标错了，写进抽查表交给老师。
23. **审核时把阿拉伯数字改成汉字**：补充句子里约两成用阿拉伯数字是故意的，不要"改规范"。
24. **Excel 存坏了文件**：要存成"CSV UTF-8（逗号分隔）"；不要排序后保存、不要加列、不要删行、不要动别人那一块和 X0482 以前的行。存完一定跑一次检查脚本。
25. **改了便携包里的 `data\classification_extra.csv`**：审核要改 U 盘上的副本。第 7 周起训练只用老师发的合并版。
26. **让 AI 替你审核或分类**：审核要人来做；不能用在线 AI、公共大模型给句子分类。可以让 AI 解释代码、解释报错（见 `docs/guides/ai_tools.md`），但不能把录音和录音转出来的文字给它。
27. **演"不耐烦"时说得太凶**：照剧本的语气演就够了。加了骂人的话既违反红线，也会让录音和剧本标注对不上。
28. **改了 `config.yaml` 的 `classify: g7` 忘了改回来**：之后演示和测评都可能悄悄用了 `g7`。看完马上改回，基线命令一定写明 `--method classify=baseline`。
29. **改了代码网页上没变化**：要关掉黑色窗口、重新双击 `start.bat`。
30. **文件保存成了别的编码**：用记事本保存时编码选 UTF-8，否则中文注释可能变成乱码，甚至运行报错。
31. **把导出的核查初稿放进 `reports\g7\`**：Word、CSV 里有同学录音的文字，ZIP 里还有片段音频，只留在本机工作文件夹，不提交。
32. **`--out` 用了同一个文件夹**：后一次的结果会盖掉前一次。基线、g7 用不同的子文件夹。
33. **机房电脑还原，东西没了**：每次下课前按"下课前拷走什么"拷到 U 盘，尤其是审核文件和训练好的模型。
