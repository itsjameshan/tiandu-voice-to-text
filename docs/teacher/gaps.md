# 还差什么（老师清单）

这份清单列出开课前后还需要老师准备、确认或决定的事。代码、文档、剧本、分类句子、便携包已经在仓库里准备好；下面这些是仓库替代不了的。按时间先后排列，做完一项就在前面打勾。

## 一、开课前必须做（第 0 周）

- [ ] **下载便携包，拷进 U 盘**：仓库首页右侧 Releases → 下载 `tiandu-portable-win64-*.zip`（约 400 MB）。详见 [portable_package.md](portable_package.md)。
- [ ] **在机房实测一台电脑**（最容易出问题的环节，一定要提前做）：
  - [ ] 解压到纯英文路径，双击 `selfcheck.bat`，看到"全部通过"；
  - [ ] 双击 `start.bat`，浏览器能打开页面，上传自己用手机录的一段 1 分钟朗读，能出结果；记下处理用了多少秒；
  - [ ] 重启电脑，看 D 盘的文件还在不在（判断哪个盘会还原）；
  - [ ] 能不能插 U 盘、能不能访问老师电脑的共享文件夹；
  - [ ] 机房自带的 Python 和 TensorFlow 版本：在命令行运行 `python -c "import tensorflow as tf; print(tf.__version__)"`，记下来给第 6、7 组。
- [ ] **录音同意书**：用 [../guides/consent_form.md](../guides/consent_form.md) 的模板，请学院确认是否需要教务或学校法务审核；打印 31 份，再多打几份给客串的同学。收回后留意两个单独勾选的条目：第 4 条（用于说话人分离的测评）决定哪些录音能做说话人标注，第 6 条（课堂演示中播放）决定答辩演示能放哪些录音；可以在线下名单上记下每个人勾了哪几条（名单不进仓库）。
- [ ] **数据池放在哪**：老师电脑上建一个文件夹（如 `D:\data_pool`），或设一个共享文件夹；准备 U 盘（建议每组 1 个，8 GB 以上）。详见 [data_pool.md](data_pool.md)。
- [ ] **录音设备**：每组至少 1 部手机和 1 根能连电脑的数据线；按 [../guides/recording.md](../guides/recording.md) 统一手机录音设置。
- [ ] **学时和周数**：每周 3—4 节 × 8 周最多 32 学时，与 36 学时差 4 学时；确定按 8、10 还是 12 周上（README 里三种排法都有）。
- [ ] **分组名单**：按 README 的分组表把 31 人分到 8 组（第 2 组 3 人），每组定组长、数据、算法、测评四个角色。**名单只在线下保存，不要放进仓库**（仓库是公开的）。
- [ ] **剧本里需要你过目的 3 处**（`data/README.md` 末尾）：景点常识；G6-S3 的 5 句标注（现在按说话人意图标为"服务态度"）；虚构名称如与真实企业重名要统一替换。

## 二、开课前建议决定

- [x] **仓库要不要设为私有**（已决定：保持公开）：现在是公开的，任何人都能看到交接包（包括 `handoff/01_对话记录/` 里的完整原始对话）和课程设计。内容都是虚构的、不含个人信息；如果不想公开，在 GitHub 仓库的 Settings → General → Danger Zone → Change visibility 改成 Private（改成私有后，学生组长需要被加为协作者才能看到）。
- [x] **"威胁消费"的显示名**（已决定）：界面和初稿上显示为"消费施压"，数据里的标签不变。
- [ ] **考核方案**：README 里有一份建议版（个人 40% + 小组 60%），按学校要求改。
- [ ] **项目介绍视频的配音**：配音模型基于仅限非商业用途的数据集训练，课堂播放没有问题；如果要发到公开平台或给政府、企业演示，请换成有授权的声音或老师自己录（字幕文件可以当配音稿）。

## 三、第 6 周前（GitHub）

- [ ] 8 个组长注册 GitHub 账号（登不上也没关系，走"老师代交"）。
- [ ] 老师把组长加为仓库协作者，打开主分支保护（必须 PR、必须自动测试通过、必须老师批准）。步骤见 [github_setup.md](github_setup.md)。
- [ ] 把 GitHub Desktop 的安装包放进 U 盘（机房没网时用）。

## 四、课程中

- [ ] 第 6 周末：数据池验收、冻结第 1 版（`tools/check_pool.py`、`tools/freeze_pool.py`），之后各组测评都用这一版。
- [ ] 第 9 周：合并各组代码、全班串联测试（[week9_integration.md](week9_integration.md)）。
- [ ] 第 10 周：答辩后打标签发布 1.0 版（[portable_package.md](portable_package.md) 末尾）。

## 五、课程之外（可选）

- [ ] **合作单位**：如果有文旅部门愿意试用，只验证一个指标——处理人员核查一份录音，用工具和不用工具各要多久。没有合作单位时，项目只有教学价值和方法验证价值，要如实说明。正式使用前要签数据处理协议、请法务确认录音的证据效力。
- [ ] **公网演示**：如果需要给外面的人在线演示，可以用魔搭社区创空间（需要老师自己的账号），只能放虚构材料。仓库里有 `Dockerfile`，部署方法见 `docs/build_spec.md` 第 10.2 节。

## 六、还没有实测、不能当作已确认的事

- 机房 TensorFlow 版本能否直接跑第 6、7 组的训练脚本（脚本按 TensorFlow 2.10 及以上的常用层写）；

- 质检阈值是保守的默认值，第 2 周试录后在 `config.yaml` 的 `qc` 一节调整。
