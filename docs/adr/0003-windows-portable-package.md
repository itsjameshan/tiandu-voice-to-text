# Windows 免安装便携包为主线，由 GitHub Actions 在 Windows 上构建

机房第 1 周没有网络、重启后会还原、学生没有安装经验，所以主线是一个解压即用的便携包（Python 3.11 嵌入版 + 全部依赖 + 模型 + ffmpeg，不含 TensorFlow），双击启动。便携包在 GitHub Actions 的 Windows 机器上构建并自测，因为开发用的云端容器访问不了 python.org，也不是 Windows；老师在有网的地方下载一次，拷进 U 盘。联网安装（虚拟环境 + 清华镜像）只作备用。

## 后果

- 新文件一律用英文路径；程序启动时检查安装路径是否含中文，临时文件放在项目内，避开中文用户名路径。
- 第 6、7 组训练分类模型时用机房自带的 TensorFlow，所以训练脚本和它依赖的文字模块不能导入 sherpa-onnx 等重依赖。
